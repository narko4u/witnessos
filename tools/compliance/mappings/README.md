# NSA MCP Security Guidance → WitnessOS Feature Mapping

Maps each finding and recommendation from the NSA's "Model Context Protocol: Security Design Considerations" (June 2, 2026) to the exact WitnessOS feature that satisfies it.

## Structure

Each mapping document covers:
- **NSA Finding** — what the NSA identified as a risk
- **NSA Recommendation** — what the NSA says to do about it
- **WitnessOS Feature** — which gateway feature addresses it
- **Evidence** — how WitnessOS provides audit-proof compliance
