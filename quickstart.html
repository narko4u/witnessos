Install WitnessOS in 15 minutes

Deploy the credential-brokered enforcement gateway on your own infrastructure. No cloud dependency, no third-party API, no vendor lock-in.

Python 3.12+ • Docker optional • Linux or macOS

Setup Steps

  1. Get access to the gateway engine
  2. Read the specification
  3. Use the public Python SDK
  4. Evaluate the architecture without the source

1. Get access to the gateway engine

The WitnessOS gateway engine (credential broker, policy enforcement, evidence chaining) is proprietary and kept in a private repository while the patent (AU 2026906017) is pending. This protects the implementation without hiding the design.

We provide NDA-protected access to:

  • Security researchers and infrastructure teams evaluating the architecture
  • Enterprise design partners integrating WitnessOS
  • Qualified investors conducting technical due diligence
Access process. Email contact@empirelabs.com.au with your organisation and use case, we schedule a 30-minute intro call, and following mutual fit we share our standard mutual NDA before granting repository access. Access is revocable at any time.

2. Read the specification

No install required. The public specification at whitepaper.html describes the evidence-grade record format, the schema, and the grading model. The interactive demo is available under NDA with the gateway access process.

3. Use the public Python SDK

The SDK is open source and works against the hosted demo endpoint:

Bash Install 
cd witnessos-sdk
pip install -e .
Python Fire a governed action 
from witnessos_sdk import WitnessOSClient

with WitnessOSClient("http://localhost:8400") as client:
    resp = client.fire_and_approve(
        to="partner@example.com",
        subject="Hello from WitnessOS",
        body="This email was governed by WitnessOS."
    )
    print(f"Case: {resp.case_id}, Receipt: {resp.receipt_id}")

    receipt = client.get_receipt(resp.case_id)
    print(f"Evidence grade: {receipt.evidence_grade}")

4. Evaluate the architecture without the source

The public repository contains everything needed to evaluate the design without exposing the implementation:

  • SPEC.md - frozen receipt specification v1.0 (E0-E4 evidence grades)
  • SECURITY.md - full security posture
  • security-review/ - R0-R7.1 adversarial review findings and mitigations
  • Whitepaper - technical deep-dive
Deployment. The full stack (docker compose up) requires the proprietary gateway engine and is available to NDA partners. Public users run the demo and SDK against the hosted demo.
