Quickstart

Evaluate WitnessOS in 15 minutes

Start with the in-browser simulation, read the public specification, and run the open-source SDK against the local demo stack. The full gateway engine is proprietary and available to NDA partners for deployment on your own infrastructure.

No install required · Python 3.12+ for the SDK · Docker optional

1. Get access to the gateway engine 2. Try the interactive simulation 3. Use the public Python SDK 4. Evaluate the architecture
Step 1

Get access to the gateway engine

The WitnessOS gateway engine (credential broker, policy enforcement, evidence chaining) is proprietary and kept in a private repository while the patent (AU 2026906017) is pending. This protects the implementation without hiding the design.

We provide NDA-protected access to:

  • Security researchers and infrastructure teams evaluating the architecture
  • Enterprise design partners integrating WitnessOS
  • Qualified investors conducting technical due diligence
Access process. Email contact@empirelabs.com.au with your organisation and use case, we schedule a 30-minute intro call, and following mutual fit we share our standard mutual NDA before granting repository access. Access is revocable at any time.
Step 2

Try the interactive simulation

No install required. The interactive simulation at demo.html runs entirely in your browser with sample data. It illustrates the governed-action flow, policy evaluation, hash-chained evidence, and signed receipts, including the E0-E4 evidence grades and exact-approval binding. No real action is executed; the gateway engine itself is not exposed publicly.

Step 3

Use the public Python SDK

The SDK is open source and works against the local demo stack included in the public repository:

cd witnessos-sdk
pip install -e .
from witnessos_sdk import WitnessOSClient

with WitnessOSClient("http://localhost:8400") as client:
    resp = client.fire_and_approve(
        to="partner@example.com",
        subject="Hello from WitnessOS",
        body="This email was governed by WitnessOS."
    )
    print(f"Case: {resp.case_id}, Receipt: {resp.receipt_id}")

    receipt = client.get_receipt(resp.case_id)
    print(f"Evidence grade: {receipt.evidence_grade}")
Step 4

Evaluate the architecture without the source

The public repository contains everything needed to evaluate the design without exposing the implementation:

  • SPEC.md, the frozen receipt specification v1.0 (E0-E4 evidence grades)
  • SECURITY.md, the full security posture
  • THREAT-ASSESSMENT.md, adversarial review findings and mitigations
  • Whitepaper, the technical deep-dive
Deployment. The full stack (docker compose up) requires the proprietary gateway engine and is available to NDA partners. Public users run the simulation in-browser and exercise the SDK against the local demo stack.
