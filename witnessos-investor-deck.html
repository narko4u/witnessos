How It Works

Agent → Policy → Chain → Case - in <50ms

1️⃣

Agent Calls WitnessOS

Before an AI agent sends an email, processes a refund, or makes any production action, it calls WitnessOS. One endpoint URL change - no SDKs, no framework forks. Drop-in middleware.

2️⃣

Policy Engine Evaluates

In under 50 milliseconds, the policy engine checks the action against configured rules: ALLOW (auto-dispatch), DENY (block), or FLAG (send for human review). Every decision is deterministic and auditable.

3️⃣

Merkle Chain Records

Every evaluation - allowed, denied, or flagged - is appended to a SHA-256 Merkle chain. The root hash provides cryptographic proof of the full history. Tamper-evident. Immutable. Verifiable by anyone.

4️⃣

Case Dispatch (if Flagged)

Flagged actions automatically route to Slack, Teams, email, or custom webhooks. Humans review, approve, or deny in one click. Every decision is logged. Human-in-the-loop without slowing the pipeline.

"Works with any agent - OpenAI, Anthropic, LangChain, CrewAI, custom. One-line change to your agent's endpoint URL. No vendor lock-in, no framework fork."

- Agent-agnostic by design
